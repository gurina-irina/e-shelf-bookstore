# E-Shelf — интернет-магазин электронных книг

Учебный проект: адаптивный лендинг книжного магазина.

## Стек:
- HTML5
- Tailwind CSS (CDN)
- Vanilla JavaScript (динамический рендеринг карточек, карусель, корзина)

## Что реализовано:
- Адаптивная верстка (Mobile-First)
- Бесконечная карусель на чистом JS
- Генерация карточек товаров из массива данных
- Логика корзины с подсчетом суммы
